# codex-plugin-oc

Use Codex from OpenCode to review code or delegate tasks.

Port of [openai/codex-plugin-cc](https://github.com/openai/codex-plugin-cc) for
OpenCode. The review and delegation engine is vendored from upstream (Apache-2.0,
see NOTICE); the command surface is rewritten for OpenCode's command/agent format.

## Status

Under development. See the `port` branch.
